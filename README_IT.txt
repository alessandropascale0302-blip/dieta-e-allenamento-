# NutriDay — versione installabile (PWA)

Questa cartella contiene la versione PWA dell'app HTML.

## Pubblicazione con GitHub Pages
1. Carica **tutti i file e la cartella `icons`** nel repository GitHub.
2. Vai in **Settings → Pages**.
3. In **Build and deployment**, scegli **Deploy from a branch**.
4. Seleziona `main` e la cartella `/ (root)`, poi salva.
5. Attendi la pubblicazione e apri l'URL di GitHub Pages dal telefono.
6. In Chrome Android: **⋮ → Aggiungi alla schermata Home** oppure **Installa app**.

La PWA include manifest, icone e service worker per consentire l'uso anche offline dopo il primo caricamento.
